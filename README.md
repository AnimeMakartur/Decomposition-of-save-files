# Cities: Skylines II Save Data Exporter

Проєкт для вилучення даних із файлів збереження **Cities: Skylines II** та підготовки структурованого опису міста для подальшого аналізу за допомогою ШІ.

## Мета

Після вибору файлу збереження проєкт має:

1. Прочитати дані міста зі збереження.
2. Відібрати потрібну інформацію про дороги, зокрема їхні типи, зупинки громадського транспорту та будівлі.
3. Об'єднати пов'язані дані у зрозумілий структурований опис.
4. Передати цей опис ШІ для подальшого опрацювання — через зовнішній API або локальну модель.

Такий підхід має допомогти аналізувати інфраструктуру міста, знаходити зв'язки між дорогами, зупинками й будівлями та формулювати висновки у зручному для людини вигляді.

## Передбачуваний процес

```text
Файл збереження
       ↓
Читання та вилучення даних
       ↓
Нормалізація доріг, зупинок і будівель
       ↓
Структурований набір даних
       ↓
ШІ через API або локально
       ↓
Аналіз і зрозумілий результат
```

Формат експорту та спосіб інтеграції з моделлю ще потрібно визначити. Серед можливих форматів для обміну даними — JSON або CSV.

## Поточний стан

Проєкт перебуває на початковому етапі. Наразі код мода містить базову ініціалізацію та повідомлення в журналі гри. Читання файлів збереження, експорт даних та інтеграцію з ШІ ще належить реалізувати.

## Інтеграція з ШІ

Передбачено два можливі способи обробки даних:

- **Через API** — передавати підготовлені дані сумісному з проєктом сервісу ШІ.
- **Локально** — обробляти дані локальною моделлю, щоб не надсилати їх зовнішньому сервісу.

Конкретну модель, API, формат запитів і спосіб запуску буде обрано під час реалізації. Для API-інтеграції ключі доступу потрібно зберігати поза вихідним кодом.

## Технології

- C#
- .NET Standard 2.1
